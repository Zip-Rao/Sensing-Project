\section{项目执行情况}

\subsection{项目选题背景、目的与意义}

% ### 1.1 研究背景与动机
% - 量子传感的基本概念与优势（灵敏度、空间分辨率）
随着摩尔定律趋于极限，经典电子器件在能耗，精度和速度等方面遇到瓶颈，为了实现更高性能的计算和测量，量子信息技术成为重要的研究方向。其利用量子态叠加，纠缠等量子资源，能够实现超越经典极限的计算和测量能力。量子信息技术包括量子通信，量子计算和量子传感三大方向\citet{bennett2000quantum}。其中，量子传感利用量子系统（如二能级系统，纠缠态等）对外界环境（磁场，电场，温度，重力等）变化的敏感性，通过量子态相位积累，能级跃迁，粒子布居数变化等途径感知外场，实现经典手段难以企及的高灵敏度和高时空分辨率的测量，被视为是量子技术最先走向实用的方向之一\citet{degen2017quantum}。
\par 在诸多物理量测量中，磁场的量子传感应用尤为广泛，覆盖材料科学中微观磁结构的探测，生物医学中神经与生理信号的记录，以及基础物理中新理论的探寻等。承担这类测量的实验平台有很多，它们各具优势，其中，超导量子比特具有成熟的微纳加工工艺，强而可控的耦合，可调谐性以及易于片上集成等优势，近年来广受关注\citet{krantz2019quantum}\citet{degen2017quantum}。其核心器件为Josephson结，该结具有非线性电感，使得超导电路在量子化后具有非简谐的能级，从而可以作为理想的人工二能级系统。当采用SQUID结构时，可以通过外加磁通调节量子比特频率，
% $$
% \omega_{01}(\Phi) = \sqrt{8 E_C E_J |\cos(\pi \Phi / \Phi_0)|} - E_C
% $$
量子比特频率对磁场变化的响应非常灵敏\citet{blais2021circuit}，实际上，已有实验利用单个超导人工原子实现交流磁场探测，并在10MHz下达到2.7pT/$\sqrt{\text{Hz}}$的灵敏度\citet{bal2012ultrasensitive}，在微波频段的磁场传感中具有巨大潜力。此外，超导量子比特可通过微波驱动线和磁通偏置线实现单比特操控，并可借助直接耦合、可调耦合器或微波谐振腔实现比特间相互作用；在 cQED 架构中，谐振腔还常用于量子态的高保真读出，这为量子传感提供了成熟的技术平台\citet{blais2021circuit}。

\par 对磁场的量子传感各类指标的优化是一个重要的研究方向。目前的该类研究还主要集中于延长相干时间和提升灵敏度，常用Ramsey，spin echo和动态解耦等协议通过延长相位积累时间来提高信号响应\citet{degen2017quantum}，这类方法适合静态场，准静态场或窄带宽场，而对于变化快，持续时间短或宽带宽信号，较长的演化时间和对时间的积分会平均信号局部时间结构，从而捕捉不到信号的细节。因此，快变磁场测量面临一个不同于传统弱场探测的问题：如何在有限的量子控制时间内建立足够强，可读出的信号响应，同时在灵敏度，估计精度和时间分辨率等指标上取得合理的平衡。

\par 在量子传感过程中，外场引起量子态的演化，在给定能量和驱动资源的约束下，该演化达到可辨识状态所需的最短时间受到量子速度极限(Quantum Speed Limit，QSL)的约束\citet{deffner2017quantum}。近年来，有研究提出了一个由两个相接的控制脉冲构成、没有独立自由演化窗口的短Ramsey型序列，并将动态信号的时间分辨率和量子速度极限联系起来\citet{herb2024quantum}。该思路随后在金刚石氮-空位中心平台上实现了纳秒量级的时间分辨能力\citet{herb2025magnetometry}。超导量子比特具有纳秒尺度的快速，可编程的微波控制能力，因此可以在更短时间内完成量子态的制备和翻转，因此是研究短时量子和高时间分辨率传感的极具潜力的平台。

\par 基于以上背景，本项目以磁通可调的Transmon 量子比特为研究对象，将这一量子速度极限启发的短Ramsey型脉冲序列引入超导量子传感框架，研究其对不同磁场信号的响应和信息提取能力，并进一步将该测控框架用于量子比特频率标定，控制线响应表征与预失真校正等任务上。项目的直接目的是建立一套从物理模型，量子测控框架，到信号反演与提取，再到具体工程优化的完整研究方法，并通过数值仿真和实验评估三项应用的可行性，精度，时间成本和适用范围等指标。为此，项目参考超导量子计算机全栈架构，构建基于QuTiP的全链路数值仿真平台，涵盖可调Transmon参数，不同信号模型，脉冲序列，测量协议的量子动力学演化以及完善的数值反演算法。该平台首先服务于物理方案的验证，同时也产出了一套基于超导量子比特的可复用的软件成果。

\par 本项目的意义体现在以下两个方面。在传感与控制层面，项目把动态量子传感中的时间分辨率问题引入超导量子比特体系，研究在系统下的比特快速控制，信号响应和提取，以及数据后处理，为理解量子速度极限约束下的快变信号测量提供了具体模型和验证路径。在测量与标定层面，项目在之前的量子快速控制框架下，进一步发展了量子比特频率标定和预失真矫正的应用，前者极大的减少了量子比特频率标定的时间成本，后者以更高的带宽实现了对控制线的响应表征和预失真校正，为超导量子计算机的高保真操控提供了可行的技术方案。项目基于超导量子计算机全栈架构开发的数值仿真平台，充分考虑了超导量子计算机的物理特性和工程约束，可以有效降低新的实验协议进入真机实验前的试错成本，同时仿真平台具有可复用性和可扩展性，为后续的超导量子器件的快速标定，控制链路优化和宽带动态磁场磁场测量提供基础，为其他基于超导量子比特的理论和实验研究提供了一个可复用的数值仿真工具。
% $$
% \tau_{QSL} \geq \max\left\{\frac{\pi \hbar}{2 \Delta H}, \frac{\pi \hbar}{2 H}\right\}
% $$
% 其先顶了量子系统从一个状态演化到另一个状态所需的最短时间的理论界限\citet{deffner2017quantum}。在量子传感中，QSL限制了量子系统对外界信号的响应速度和时间分辨率。若信号变化的时间尺度短于QSL，则量子系统无法完全响应信号变化，导致测量误差增加。因此，发展能够近似达到QSL的量子传感协议对于提升瞬态磁场测量的性能具有重要意义\citet{herb2024quantum}。

\subsection{项目创新点与特色}
本项目围绕快变磁场量子传感中的时间分辨率分体，将受量子速度极限启发的短Ramsey型脉冲序列引入磁通可调Transmon 量子比特体系，并进一步面向量子比特测控与表征需求拓展其应用范围。项目的创新点与特色主要体现在以下几个方面。
\vspace{1em}
\par Herb等提出的瞬态传感协议以量子比特末态布居数对瞬态失谐的响应为基础，在线性响应近似下，测量信号可以表示为一阶响应核与失谐频率的卷积\citet{herb2024quantum}。将这一框架应用于磁通可调Transmon量子比特时，还需处理量子比特频率对外加磁通的非线性响应。如果先由测量结果反演失谐频率，在通过局部频率-磁通色散关系恢复外场，则反演精度依赖于色散关系及其参数的准确性，采用局部线性化时，还会受到小信号条件和工作点选择的限制。

\par 针对这一问题，本项目从两个方向扩展了瞬态传感协议的响应理论。首先，将一阶线性响应推广为多阶Volterra泛函展开，用多节响应和描述较大信号幅值下的非线性修正，并区分同一时刻的对角核与不同时刻耦合的完整非对角核。其次，建立频率核与磁通和两种模式：频率核直接描述末态布居数对失谐频率扰动的响应，适用于频率测量和已知色散关系下的分析；磁通核则直接描述末态布居数对外加磁通扰动的响应，将Transmon 的非线性频率-磁通色散关系纳入响应模型，可以减少额外局部线性转换带来的模型与参数误差。两种核函数可以根据待测物理量和实验标定条件选用，从而适配不同的测量任务和实验条件。
\vspace{3em}
\par 为了能够对核函数进行理论分析，同时也能在实验中进行独立标定，本项目基于目前已有的核函数数值方法\citet{lin2025application}和实验+数值方法\citet{herb2025magnetometry}，进一步完善了核函数的理论与实验求解方法。理论求解基于已知控制脉冲哈密顿量和传播子，通过海森堡绘景中的嵌套对易关系计算频率响应核，适合开展高精度理论分析和多阶完整核的数值验证。实验求解则通过在脉冲演化期间的不同时刻施加可控的Virtual-Z相位探针或施加一个瞬时的磁通微扰，并利用末态布居数测量的有限差分恢复核函数，该方法则需要测量末态结果，不需要预先知道完整的哈密顿量，因此可以用于实验核函数标定和理论模型的验证。
% \par 此外，本项目还推广了核函数的求解方法，目前针对核函数的求解还停留在实验+数值\citet{herb2025magnetometry}或者纯数值\citet{lin2025application}的形式。本项目提出了一种基于超导量子比特的纯实验的方法，可以直接通过测量结果求解核函数，从而避免了数值模拟中可能存在的误差，并且可以直接在实验中验证核函数的正确性。
\vspace{1em}
\par 本项目还基于超导量子计算机全栈架构，搭建了一个基于QuTiP的全链路数值仿真平台，该平台可以自定义Transmon参数，磁通信号，控制脉冲，并自主编排量子动力学演化协议实验。目前，平台已经内置了多种演化协议，包括Rabi振荡，Ramsey干涉，差分回波，基于tomography的cryoscope协议和Ramsey协议，基于$\pi$脉冲补偿的测量协议以及上述的短Ramsey型脉冲协议等等。平台还包含了多种数据处理算法，可以从仿真或真机实验产生的测量数据中提取到需要的信号信息。

\par 在测量与控制方面，平台实现了频率-磁通响应标定，Ramsey/短Ramsey型脉冲协议单点测频，量子比特频率闭环反馈控制，控制线波形表征和补偿，并通过统一的标定表和调度接口组织相关任务。这些接口主要服务于数字仿真、实验流程设计和数据分析，部分接口可以直接接入实际测控系统参与测控任务。

\par \begin{mdframed}最后，本项目在仿真平台上测试了上述短Ramsey型脉冲的任意波形重建能力，并将其高带宽的信号响应能力应用到\citet{rol_time-domain_2020}的预失真框架中，实现了对超导量子比特控制线的高带宽响应表征和预失真校正。另外，本项目还将该脉冲应用于量子比特频率标定任务中，利用其短脉冲的相位积累和提取能力，纳入到\citet{vepsalainen2022improving}的闭环频率标定框架中，大幅度降低了频率标定的时间成本。以上两项应用都在超导量子计算机的控制和测量中具有重要的工程价值，其中，为了测试第二项应用的价值，本项目还在真机上具体验证了其可行性和应用价值。\end{mdframed}

\subsubsection{项目执行情况}
项目立项时以超导量子比特的磁场传感为研究对象，拟研究灵敏度，测量精度和时间分辨率之间的协同关系，比较并优化多种传感脉冲序列，依托实验平台开展实验验证，并形成传感协议的综述和论文等成果。项目实施后，研究主线由较宽泛的“不同序列，多项指标参数协同优化”逐收束到围绕同一类型脉冲序列的传感与控制框架，建立超导量子比特的传感与测控技术的工程优化上来，并进一步面向超导量子比特传感、标定和控制链路表征中的具体工程问题开展研究调整后的工作集中于三项应用上：时变磁场的波形重建，量子比特频率标定以及控制线响应表征与预失真矫正中。

\par 原定计划的及路线调整后的主要完成情况如下：
\begin{enumerate}
    \item \textbf{传感模型与数值平台：} 完成了基于磁通可调 Transmon 量子比特的磁场传感模型，建立了量子比特对磁通信号的频率响应、控制脉冲作用、开放系统演化和末态测量之间的理论与数值联系，并对短 Ramsey 型脉冲序列及其响应核开展了理论推导和分析。在此基础上，构建了基于超导量子计算机全栈架构的数值仿真平台，并完成了平台架构说明、技术文档、测试和工作流说明。

    \item \textbf{时变磁场波形重建：} 围绕快变磁场的波形重建，建立了短 Ramsey 型脉冲序列的等效时间采样测量与响应核提取方法，并形成 Wiener 反卷积和全密度矩阵 Levenberg--Marquardt 反演两类重建路径。项目已获得不同波形、信号幅值、正则化参数和算法收敛条件下的仿真结果，以及不同协议下的仿真对比分析。

    \item \textbf{量子比特频率标定：} 将短 Ramsey 型脉冲的正交测量响应用于量子比特失谐估计，建立了从单点频率测量到闭环频率反馈的标定流程，并在数值平台和实验平台上进行了与标准 Ramsey 基线的精度和时间成本比较。该应用的目标是在给定精度下减少闭环标定的测量与时间成本。

    \item \textbf{控制线响应表征与预失真校正：} 面向磁通控制脉冲经过控制链路后产生的幅度衰减、延迟和拖尾失真，建立了从失真测量、响应辨识、逆滤波到补偿验证的分析流程。项目在仿真平台中建立了控制线失真模型，并比较了短Ramsey脉冲序列和Cryoscope、延迟 Ramsey 等表征路径的带宽和精度。

    \item \textbf{实验验证与成果产出：} 项目围绕量子比特频率标定设计了短 Ramsey 型脉冲的闭环实验验证流程。\textbf{[EXPERIMENTAL PLACEHOLDER：提交前填写真实器件、实验次数、误差定义、主要结果、图号和数据路径，并据此将本句改写为已完成或部分完成。]} 在成果整理方面，项目已形成软件平台、架构说明和技术文档；\textbf{[TO BE REPLACED：提交前填写已发表论文的真实题名、作者、期刊、年份、文章号或 DOI 及项目资助标注。若届时无正式发表证明，不得写为“已发表”。]}
