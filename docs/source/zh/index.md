# sqc — 超导量子比特磁场传感仿真平台

```{note}
本文档站正在建设中。页面正在逐步填充;下方结构反映规划的“框架优先”布局。
```

**sqc** 是一个基于 QuTiP 的、可组合的全栈仿真框架,用于超导 Transmon 量子比特控制与磁场传感研究。

三条内置科研主线(波形重建、频率标定、预失真)是组合各层的**范例**,而非平台能力的
边界。每一层都暴露扩展接口,可据此构建新的传感应用。
