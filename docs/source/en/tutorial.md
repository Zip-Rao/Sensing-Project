# Full Example

This end-to-end notebook runs the three pipelines from the
{doc}`worked examples <examples/index>` in full: waveform reconstruction,
frequency calibration, and predistortion. It builds a qubit, applies a flux
signal, simulates with QuTiP, and performs reconstruction, calibration, and
compensation, with the resulting numbers and plots. It is the runnable version
of the worked examples: the examples give the shortest call sequence, while this
page gives the full flow with output and intermediate results. The outputs are
pre-rendered, and the notebook can also be run locally after installing the
`[demo]` extra.

```{note}
The notebook is currently authored in Chinese; an English walk-through is
planned. The code and outputs are language-neutral.
```
