可直接摘入报告或论文。两类图的约定见各节:

- **sqc 独立图**(报告候选):仅原波形 + sqc 重建,无 src 叠加。

## 1A. D1_waveform_reconstruction — 代表性重建与正则化(图 D1)

扫描 type=4 阶跃信号幅度 A ∈ {0.01 … 0.1},每幅度做一次 Wiener 重建。

### `amplitude_scan_results_sqc.png`(★报告候选)
- **展示**:双 panel。左:峰值比 vs 幅度(过 r=1 参考线);右:RMSE vs 幅度(log-log)。

- **物理含义**:线性 Wiener 反演要求相位 φ_max = κ·A·t_free ≲ 1 rad;幅度越

## 6. workpoint_comparison — 工作点效应(新增,无 src 对应)

同一高斯信号在三个工作点重建。这是 sqc 新增图,凸显瞬态传感的核心约束。

### `workpoint_comparison_sqc.png`(★报告候选)
- **展示**:1×4。前三格 (a)-(c):三个代表性工作点(甜点 Φ=0 / 线性
  Φ=0.9553 / 非线性 Φ=0.25)的重建 vs 真值快照,标题含 κ=dω/dΦ,右下角标峰值比 r。
  第四格 (d):**RMSE vs 带符号灵敏度 κ 的密扫谷形曲线**(21 点,Φ∈[−0.45,+0.45],
  log-y),三个命名点作为红色标记叠在曲线上。
- **如何读**:(a)-(c) 看重建贴合真值程度;(d) 看 RMSE 谷底位置——存在一个最优 κ。
- **物理含义**:传感灵敏度 κ=dω/dΦ 决定成败,判据 φ_max = κ·A·t_free ≲ 1 rad。
  - 甜点 κ=0:核病态,信号无法编码 → 失败(r=0.47,RMSE 高)。
  - 线性 φ_max≲1 rad:忠实重建(r=0.995,RMSE 最小)。
  - 非线性 κ 大 φ_max≫1:相位卷绕振荡(见 (c)),Wiener 欠恢复(RMSE 高)。
- **(d) 为何这样设计(而非 3 点/磁通/峰值比)**:
  1. **密扫 29 点、甜点附近加密**替代原 3 点,才能体现连续趋势并解析 κ→0 行为。
  2. **横轴用带符号 κ**:f01(Φ) 关于甜点偶对称,κ 在两侧反号(Φ<0 侧 κ>0,
     Φ>0 侧 κ<0),故横轴直接读出色散斜率正负,曲线大致关于 κ=0 对称。
  3. **纵轴用 RMSE 而非峰值比**:峰值比在大 \|κ\| 处**不可靠**——相位卷绕振荡
     (见 (c))会让重建峰值超过真值,peak_ratio>1 是过冲假象而非恢复变好。
     RMSE 给出干净的 **W 形**:κ=0 中间隆起(病态)、最优 κ 双谷、大 \|κ\| 两翼卷绕。
- **甜点处的隆起是"局部极大"不是奇点**(常被误读):κ=0 处 RMSE=1.47e-3 有限,
  加密采样(κ=−5.6→−4.4→−3.1→−2.0→−1.0→0:RMSE 3.2e-4→…→1.47e-3)显示
  是**平滑上升到峰**,无数值发散/毛刺;Wiener 正则化 λ=5 保证核趋零时不除零。
  物理上甜点 κ=0 → 一阶磁通不敏感 → 信号不被转导 → 反演失效(peak 0.47)。
  之前粗网格版看着像"针尖"是欠采样 + log 轴假象。
- **甜点邻域轻微不对称**(诚实标注):κ=+0.99 处 RMSE=2.2e-3 略高于对称点
  κ=−0.99 的 7e-4。根因非噪声(noise_level=0),而是信号幅度 A=0.01 与偏置
  \|Φ\|≈0.008 同量级,磁通轨迹 Φ_bias+signal(t) 横跨甜点使 κ 在信号期间变号
  ——真实的简并/强非线性区,非 bug。
- **关键数值**:RMSE 谷底在 **κ=5.6(=线性工作点)**,RMSE_min=1.77e-4;
  三快照 κ = 0 / 5.55 / 33.2,峰值比 = 0.47 / 0.995 / 0.65,RMSE = 1.46e-3 /
  1.78e-4 / 3.08e-3。谷底恰在线性点,定量验证 φ_max≲1 判据。

#### A. 时间分辨率(子任务 A)

- **物理含义**:分辨极限由**控制核有效宽度 σ_k** 决定,**不是** 0.5 ns 的 AWG
  采样间隔。固定单峰 σ=5 ns,只扫峰间距(用 `FluxSignal(type=8)` 自定义数组;
  `type=5` 把间距和宽度绑在同一个 `width` 上,做不了这个扫描)。
- **关键数值**:
  - 核 **σ_k = 3.386 ns**,**FWHM(|k|) = 12.648 ns**(单主峰、全程不变号,故 FWHM
    有意义)。FWHM/σ_k = 3.73 略大于高斯的 3.33 → 核比高斯**更平顶**。
  - **真值几何天花板 Δt_min = 13.31 ns**;**Wiener = 14.49 ns**;两者均被
    扫描区间**括住**,无外推。LM 诊断值 17.89 ns 不进入主图。
  - Wiener 首个满足全部判据的间距是 **15 ns(C_v=0.244)**。
- **⚠ 三条容易写错的点**:
  1. **真值自己就有天花板**:两个 σ=5 ns 高斯在 Δt ≤ 2σ=10 ns 时**输入本身是
     单峰**(Cv_truth=0),任何传感器都不可能分辨。所以 13.31 ns 是**信号几何**
     限制,不是传感器指标;报告 Δt_min 必须同时给出它,否则把几何当成分辨率。
  2. LM 诊断值为 17.89 ns,差于 Wiener 的 14.49 ns,主要反映当前 fourier
     `n_basis=100` + λ=100 的平滑作用；该结果保留在诊断版和 metrics 中。
  3. **NRMSE 全程 0.022–0.031**,从不是约束项 —— 判据实际由 C_v 决定。诚实
     写法:NRMSE 只作宽松 sanity gate。
  4. C_v 为 NaN 表示"检出峰 <2 个",是**确定不可分辨**,不是缺数据;算穿越点
     时按 0 处理(见 `_d2_common.contrast_for_crossing`)。

#### B. 灵敏度(子任务 B)

- **物理含义**:噪声是**显式的二项投影噪声**,信号臂与零磁通参考臂**各自独立
  抽样**后再作差:`n_i ~ Binomial(N_shot, p_i)`,`p̂_i = n_i/N_shot`。零信号基线
  是**单独跑的正向模型**(A=0 时两臂理想布居相同但独立抽样,展宽即纯散粒噪声),
  不是从有信号结果尾部估的。幅度用**模板投影** `Â=⟨φ̂,s⟩/⟨s,s⟩`,不用单点峰值。
- **关键数值**:
  - 噪声底 σ_Â,0(64 种子)= **1.006e-4 / 4.007e-5 / 1.061e-5**,对应
    N_shot = 1e3 / 1e4 / 1e5 —— 跨 100× shot 降 **9.48×**(理想 10×)。
  - **A_min(SNR≥3)= 2.475e-4 / 1.085e-4 / 2.912e-5 Φ₀**,三点**全部被扫描
    区间括住**(bracketed),无外推。
  - 面板 (d) 拟合斜率 **−0.46**(理想 −0.5)→ 确认确实是**散粒噪声限制**。
  - 零信号均值 **−5.0e-6 / −8.0e-6 / +1.1e-6**,以各自 SEM 计为
    −0.40 / −1.60 / +0.81 σ → 与 0 一致,基线无偏。
  - **Wiener 幅度过恢复**:Â/A 在 A=2e-4…1e-3 处平台 **1.18**;A=3e-3 回落到
    1.153(饱和起点);A=1e-5 处 0.900 是噪声主导,非增益。
  - **LM 幅度近乎无偏**:Â/A = **0.968 / 0.988 / 0.997**(A=1e-4/3e-4/1e-3),
    随幅度收敛到 1;同 N 下 Wiener 是 1.103/1.160/1.172。
  - **LM 噪声底反而更低**:σ_Â,0(LM, 6 种子)= 2.245e-5,比 Wiener 同 shot 的

  - **成本对比**:灵敏度扫描 Wiener 反演累计 **0.3 s**(1344 次),LM 18 次
    **5452 s** —— 约 **1.8 万倍**。正向模型 13 次另计 92.6 s(两法共享)。
- **⚠ 三条必须照抄的限制**:

     读出/复位时间**,占空比未知 → 只报"给定散粒噪声模型下的 A_min"。
     **不得**拿求解器墙钟时间冒充采集时间,**不得**输出 Φ₀/√Hz 数值。
  2. **A_min 是"该估计器的"检测阈**,不是增益校正后的物理幅度:Wiener 幅度
     估计在扫描区间上端 `Â/A ≈ 1.2`(过恢复)。
  3. **κ_φ = dω/dΦ 是转导斜率,不是灵敏度** —— 本节不把它当灵敏度报。
  4. **LM 与 Wiener 的 shot 预算不对等**:Wiener 用差分观测(两臂),而 sqc 的
     LM 重建器只吃信号臂的绝对 `p_meas`(半数电路执行)。两条 SNR 曲线**不是
     等价比较**;LM 点数少(冻结子集),`a_min_lm` 存 NaN 而非硬凑一个数。
     LM 的 σ_Â,0 只有 **6 个种子**(相对不确定度约 30%),因此 LM 点不进入报告
     主图；诊断版中的菱形不带误差棒,不得解释为标定好的 LM 灵敏度曲线。

#### C. 两法总结(不要写成"LM 全面更好")

| 维度 | Wiener | LM | 胜者 |

**结论**:D2 主图用于给出统一 Wiener 口径下的时间分辨率和检测下限。两法取舍
