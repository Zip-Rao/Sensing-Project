# P9 short-time distortion benchmark

This directory implements the pre-registered §3.1-E benchmark for 2--30 ns
control-line dynamics. It does not replace P6--P8.

The measurement layer is a protocol-level noisy numerical emulator. The
transient branch uses the first-order kernel frozen by the project's P8 QuTiP
simulation; the Cryoscope branch uses cumulative phase, matched I/Q binomial
sampling, and a fixed Savitzky--Golay derivative. Both branches use the same
time grid, shots per arm, seed set, gain-calibration split, cross-spectral
estimator, 64-tap regularized FIR rule, and held-out waveforms.

Run from the repository root with the project environment:

```powershell
& 'C:\Users\21034\anaconda3\envs\qutip-env\python.exe' `
  result_sqc/predistortion/P9_short_time_distortion_benchmark/generate_short_time_benchmark_sqc.py
```

`metrics.json` is authoritative for G0--G3. Gate-level G4 is generated by the
separate CZ script and must not be inferred from waveform RMSE alone.

After the measurement benchmark, run `generate_cz_validation_sqc.py`. It first
applies the pre-registered G1--G3 gate. In the frozen 2026-08-05 run, the gate
fails and the script records a machine-readable stop instead of generating a
misleading CZ heatmap. P7 remains the separate Cryoscope-only Hamiltonian
reference.
