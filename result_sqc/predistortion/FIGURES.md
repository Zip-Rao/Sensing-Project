# 块 3 图注说明(波形预失真 `predistortion/`)

块 3 是 sqc **新增能力**,`src/` 无对应基准,故只画 sqc 自身物理正确性图
(与解析真值对比,不叠加 src)。每张图按四段式:**展示 / 如何读 / 物理含义 / 关键数值**。

> **目录约定(v2)**:每张图独占一个子文件夹 `P<n>_<slug>/`,内含该图的
> **脚本 + 数据(.npz)+ 图(.png/.pdf)**。子夹清单:
> `P1_distortion_gallery/`、`P2_correction/`、`P3_transfer_fit/`、
> `P4_improvement_vs_strength/`、`P5_protocol_driven/`。

通用设置:采样 `dt=CONFIG.awg.dt=0.5 ns`(R9:时间轴一律 `np.arange` 派生);
失真模型来自 `sqc.hardware.distortion`;物理参考 Gao 2021 §III.D(控制线传递函数)、
§V.E(Cryoscope 标定失真尾)。⭐ = 论文重点。

## P1 — 失真模型图谱:阶跃响应 + Bode

图文件:`P1_distortion_gallery/distortion_gallery_sqc.png/.pdf`,
数据:`P1_distortion_gallery/distortion_gallery_sqc.npz`

- **展示**:6 个代表模型的 2×2 面板。(a) 阶跃响应 s(t) 全窗 0–500 ns;
  (b) **尾偏差 |1−s(t)| 对数 y**(同一 500 ns 窗);(c) Bode 幅度 dB,log-f
  1e-4–1 GHz(含**线性-f inset** 放大 −1..0.1 dB 的直通平台);(d) Bode 相位 deg。
  6 条曲线分两族:
  - **指数族**(物理 rad/ns 频响):`single_exp` A=0.05/τ=100 ns(蓝实)、
    `single_exp smooth` τ=100 ns(浅蓝虚)、`multi_exp` (0.04,80ns)+(0.02,400ns)(红实)、
    `cascade` (0.05,50ns)→(0.03,200ns)(绿实)
  - **滤波族**(归一化 dt=1 频响,详见下方坑位):`FIR` echo 0.05@4 ns(紫点划)、
    `IIR` 一阶低通 f_c=200 MHz(橙点)
  `CustomTransferDistortion` **未纳入** —— 它要求用户自供 H(ω) 网格,没有代表性参数集。
- **如何读**:
  - (a) 看**是否 t=0 跳变**:5 条从 (1−A) 起跳(有 δ 直通路径),只有 smooth 从 0
    平滑爬升(纯低通)。看谁最晚贴到 1。
  - (b) **对数 y 上指数尾是直线,斜率 = −1/(τ·ln10),可直接读出 τ**。这是 (a) 分不开
    的地方(指数族在 (a) 里全挤在 0.92–1.0):multi_exp(红)斜率最缓 = 400 ns 长尾;
    single_exp(蓝)最陡。灰点线为 10⁻³ 整定带 —— 穿过它的时刻即 settling time。
    FIR/IIR 触底压在 1e-5 floor(它们**精确**整定,几 ns 内到 0)。
  - (c) 直通族在主图上全贴 0 dB,**必须看 inset**:平台高度 = 20log₁₀(1−ΣA);
    FIR 呈梳齿(周期 = 1/延迟 = 0.25 GHz)。只有 smooth / IIR 真正滚降。
  - (d) 一阶极点各贡献 −90°:smooth 在 1.6 MHz 转折,IIR 在 200 MHz。
- **物理含义**:控制线从 AWG 到片上磁通的传递函数不是恒等 —— 这张图是**预失真要
  对付的对手图谱**。三种物理机制:
  - **电荷再分布尾**(指数族,Gao 2021 §V.E):阶跃后缓慢爬升,DC 增益仍为 1,
    但 τ 量级 10–1000 ns,直接污染同尺度的磁通脉冲。`smooth` 标志区分「有无直通
    路径」:`smooth=False` 保留输入不连续性(宽谱),`smooth=True` 是纯低通。
    多时间常数(multi_exp)与串联级(cascade)是真实器件的常态。
  - **反射回波**(FIR):阻抗失配导致主脉冲后 4 ns 出现 5% 回波 → 频域**梳状**
    纹波,周期严格 = 1/延迟。这是 FIR 型失真的教科书形状。
  - **带宽限制**(IIR):冷线/滤波器一阶滚降,f_c=200 MHz,**无长尾但有相位延迟**。
  分族的意义:指数族是**慢尾**(时域问题,DC 增益无损),滤波族是**带宽**
  (频域问题,尾巴几 ns 就没)。两者需要的逆滤波器完全不同 —— 这是 P2/P3 的前提。
- **关键数值**(脚本 stdout 逐行打印,均与解析值逐位吻合):

  | 模型 | s(0) | settling (10⁻³) | f_−3dB |
  |---|---|---|---|
  | single_exp A=.05 τ=100 | 0.9500 | 391.0 ns | 无(平台 −0.45 dB) |
  | single_exp smooth τ=100 | 0.0000 | 690.5 ns | 1.6 MHz |
  | multi_exp (.04,80)+(.02,400) | 0.9400 | 1198.0 ns | 无(平台 −0.54 dB) |
  | cascade (.05,50)→(.03,200) | 0.9218 | 683.0 ns | 无(平台 −0.72 dB) |
  | FIR echo .05@4ns | 0.9524 | 3.5 ns | 无(梳齿 0..−0.87 dB) |
  | IIR f_c=200 MHz | 0.2391 | 5.0 ns | 193.9 MHz |

  解析核对:settling `100·ln(0.05/1e-3)=391.2`✓、`100·ln(1000)=690.8`✓、
  `400·ln(0.02/1e-3)=1198.3`✓;平台 `20log₁₀0.95=−0.446`✓、`20log₁₀0.94=−0.537`✓、
  `20log₁₀(0.95·0.97)=−0.710`✓;FIR 梳齿下界 `20log₁₀(0.95/1.05)=−0.868`✓;
  IIR 实测 193.9 MHz vs 设计 200 MHz = **双线性变换的频率翘曲**(非误差)。
- **关键坑位(务必记住)**:**两族频响的 ω 单位不同**。指数族
  (`SingleExponential`/`MultiExponential`/`Cascade`)的 `frequency_response(omega)`
  是**物理 rad/ns**;`FIRDistortion`/`IIRDistortion` 是**归一化 dt=1**
  (`distortion.py:597` / `:745`,docstring 明写 "nominal dt=1")。要把 6 条画在同一
  Bode 轴上,滤波族必须传 `omega*DT`(DT=0.5 ns)。交叉验证:这样传之后 IIR 恰好
  在其设计转折 200 MHz 附近落到 −3 dB;若忘了乘 DT,频率轴会整体错 2×。
- **实现注记(诚实标注)**:
  1. **settling 用独立长网格**(`T_SETTLE_END=3000 ns`)算,不用绘图窗口。multi_exp
     的 400 ns 尾需 ~1200 ns 才进 10⁻³ 带,若只在 500 ns 窗内求会得到 `nan`;
     而把绘图窗拉到 3000 ns 又会压死前沿结构。settling 是**指标**不是曲线,故分离。
  2. **FIR 用因果回波,不用居中高斯**。先试过 ±2σ 截断的高斯(AWG 重建滤波器),
     被否:截断旁瓣 −35 dB 把 (d) 相位 unwrap 撕成锯齿,且其群延迟在共享相位轴上
     压过整个指数族。回波模型物理同样真实(阻抗失配)且频响解析干净(±0.87 dB /
     ±2.9°)。
  3. **(b) 的 1e-5 地板**与 **(c) 的 1e-4 幅度地板**是 log 轴 clip:双线性 IIR 在
     Nyquist 处 |H| 精确为 0(1.9e-17),FIR 回波尾在 4 ns 后精确为 0。
  4. (d) 中 FIR 相位仅 ±2.9°,在跨 −90° 的共享轴上近似贴 0 —— 是真实行为
     (短回波几乎无净相移),非绘图失效。

## P2 — 预失真校正前后:匹配 vs 失配模型

图文件:`P2_correction/predistortion_correction_sqc.png/.pdf`,
数据:`P2_correction/predistortion_metrics_sqc.npz`

- **展示**:`PredistortionValidationWorkflow` 端到端(注入已知失真 → 测阶跃 → 拟合
  H(ω) → 设计逆滤波 → 施加 → 验证)在**两种场景**下的 2×2 面板。目标波形是
  **flat-top**(50–250 ns 方波,窗 500 ns),而非裸阶跃 —— 上升沿暴露缓爬尾、
  下降沿暴露镜像残余尾,两者都是真实磁通脉冲会挨的。
  - (a) **matched**:真值 single_exp(A=0.05, τ=100 ns),拟合类也是 single_exp。
  - (b) **mismatch**:真值 2 分量 multi_exp((0.04,80ns)+(0.02,400ns)),拟合用
    3 分量 multi_exp(workflow 的 `n_exp_components=3`)。
  两图各画 target(黑)/ on-chip 未校正(红)/ on-chip 已校正(蓝虚),右侧 inset
  放大上升沿后的 flat-top 爬升。(c) 残差 |on-chip − target| 对数 y,四条(两场景 ×
  校正前后)。(d) **AWG 实际播放的波形** —— 过冲 + 尾部下垂。
- **如何读**:
  - (a)/(b) 主图里蓝虚线与黑线**完全重合**,肉眼分不出 —— 必须看 inset 和 (c)。
    inset 中红线从 (1−ΣA) 缓慢爬向 1(matched 0.95→0.98,mismatch 0.94→0.97),
    黑/蓝重合在 1.0 —— 这就是校正效果。
  - (c) 是**真正的判据**:未校正(浅色实线)停在 ~1e-2;matched 已校正(蓝虚)
    压到 **1e-15**(机器精度);mismatch 已校正(橙虚)停在 **~1e-4 的真实地板**。
    两者相差 **11 个数量级** —— 中间那条空带不是画图失误,它**就是结论**。
  - (d) 看代价:为让片上平坦,AWG 必须在边沿过冲到 **1.05/1.06**、在下降沿后
    下垂到 **−0.046/−0.048**。这决定了 AWG 的动态范围余量需求。
- **物理含义**:**为什么必须画两个场景**(这是本图的核心设计,别删掉任何一个):
  `WaveformCalibration._fit_step_response` 确实在跑 `curve_fit`
  ([waveform.py:203](../../sqc/calibration/waveform.py#L203)),**不是**把注入参数读回来。
  但当**拟合模型类 == 真值模型类**时,用 single_exp 去拟合 single_exp 的阶跃响应
  是精确的(回收 `{'amplitude': 0.05, 'tau': 100.0}`,逐位等于注入值),于是逆滤波器
  成为**代数精确抵消**,improvement 冲到 ~3e12。
  这个数**是真的,但它是同义反复** —— 只证明「已知模型的精确逆能抵消它自己」,
  单独拿出来会是一张误导性的图(审稿人必然追问)。所以 P2 同时给出:
  - **matched = 算法上限**:证明 pipeline(测量→拟合→设计逆→施加)本身无实现错误,
    残差只受浮点限制。这是**必要的正确性基线**。
  - **mismatch = 真实器件**:真实控制线有多个尾时间常数,而标定模型阶数有限。
    3 分量拟 2 分量真值(过参数化)时拟合会**退化分裂**:恢复出
    0.00806+0.01194=0.0200 @ τ≈400 ns、0.04 @ τ≈80 ns —— 分量个数对不上但
    **物理和正确**。残留的 ~1e-4 地板来自离散化与拟合的有限精度,不是 bug。
  真实器件标定应当参照 **mismatch 的 ×108**,而不是 matched 的 ×3e12。
- **关键数值**(脚本 stdout 逐行打印):

  | 场景 | rmse 未校正 → 已校正 | improvement | max\|e\| 未→已 | settling | 逆滤波器类型 |
  |---|---|---|---|---|---|
  | matched | 2.075e-2 → 7.207e-15 | **×2.88e12** | 4.99e-2 → 1.15e-14 | 500 → 0 ns | `IIRDistortion` |
  | mismatch | 2.512e-2 → 2.334e-4 | **×108** | 5.99e-2 → 5.98e-4 | 500 → 0 ns | `CascadeDistortion` |

  AWG 动态范围:matched −0.0461..+1.0525,mismatch −0.0481..+1.0634。
  两场景 settling 都是 500→0 ns:未校正在 500 ns 窗内**从未**进入 10⁻³ 带
  (返回窗口末端),校正后**立即**在带内(返回 0.0,见
  [`_settling_time`](../../sqc/workflows/predistortion_validation.py#L195) 的语义)。
  逆滤波器类型由 `PredistortionDesigner(method="auto")` 自选:matched 出一阶
  `IIRDistortion`,mismatch 出 `CascadeDistortion`(多极点需级联)。
- **实现注记(诚实标注)**:
  1. **(c) 中 mismatch 已校正曲线在 t≈85 和 t≈235 有向下尖刺**(掉到 1e-7)。
     这是残差**过零变号**,在取绝对值的对数轴上必然显示为尖峰,不是数值不稳。
  2. **(c) 的 1e-16 地板**是 log 轴 clip(matched 残差在脉冲外精确为 0)。
  3. inset 放在**右侧** t>280 的真空区,不能放左下 —— 那里会挡住下降沿后的残余尾巴,
     而那正是 (a)/(b) 要展示的内容之一。
  4. **P4 的隐患(做 P4 时必须处理,另见 P3 节)**:P4 骨架扫的是 matched single_exp 强度
     (`STRENGTHS=[0.01..0.10]`, `FIXED_TAU_NS=100`)。按本节的分析,matched 情形下
     improvement 恒为代数精确抵消,**P4 会得到一条 ~1e12 的水平线,与强度无关**,
     图毫无信息量。P4 必须引入模型失配(或测量噪声)才有真实趋势。
     **注意**:P3 已证明「有限标定窗」这条路**走不通**(解析阶跃无噪声 → 窗长不影响
     拟合精度),所以 P4 只剩「模型失配」和「测量噪声」两个选项。

## P3 — 传递函数拟合质量与模型阶数选择

图文件:`P3_transfer_fit/transfer_fit_quality_sqc.png/.pdf`,
数据:`P3_transfer_fit/transfer_fit_quality_sqc.npz`

- **展示**:`WaveformCalibration(method="transfer_function")` 测阶跃 → `curve_fit`
  拟合 → `to_distortion_model()`,真值已知故可同时评分**阶跃拟合**与**参数回收**。
  三种真值:`single`(1 极点)、`multi2`(0.04,80ns)+(0.02,400ns)(2 极点)、
  `cascade`(0.05,50ns)→(0.03,200ns)(2 极点)。2×2 面板:
  (a) 2 极点真值的 measured(灰粗)vs fitted,K=1(红虚)/ K=2(蓝实)/ K=3(紫点);
  (b) 拟合残差 |s_fit − s_meas| 对数 y,同三个 K;
  (c) **rms vs K**(K=1..5),三条真值曲线,**空心圈标出各自真实极点数**;
  (d) 正确阶数下每个 (A_k, τ_k) 的**相对回收误差**(实心=幅度,斜纹=τ)。
- **如何读**:
  - (a) 只有 K=1(红虚)肉眼偏离灰线;K=2 与 K=3 都压在数据上 —— 说明**欠拟合可见,
    过拟合不可见**(必须看 (b)/(c) 才能分辨)。
  - (b) 是判据:K=1 残差停在 ~5e-3 的**结构性地板**(形状是残余的双指数差),
    K=2 掉到 ~4e-11,**相差 8 个数量级**;K=3 反而回到 ~1e-8。
  - (c) 核心图:**rms 在 K=K_true 处暴跌,之后非单调散布**。圈标处即真实极点数。
  - (d) τ 的回收(斜纹)普遍比幅度(实心)精确若干数量级 —— 见下方物理含义。
- **物理含义**:
  - **为什么信息轴是阶数 K,而不是标定窗长**。原本预期「Cryoscope 只测到有限时间 →
    窗太短看不到尾巴平台 → 拟合有偏」。**实测证伪**:把 `t_max` 从 20 ns 扫到 2000 ns
    (t_max/τ = 0.2 … 20),幅度与 τ 的相对误差始终 <1e-9。原因是**解析阶跃无噪声**,
    而指数和被它的**任意有限弧唯一确定** —— 窗长在解析路径上是**死轴**。真实实验里
    窗长之所以重要,是因为有噪声;解析路径没有。所以拟合质量完全由 **K 是否匹配真实
    极点数**决定。(这条结论直接约束了 P4 的可选方案,见 P2 节注记 4。)
  - **K=1 欠拟合给出「加权折中」参数,不是随机值**:multi2 → A=0.05303(≈0.04+0.02
    但略高)、τ=172.47 ns(**介于 80 和 400 之间**);cascade → A=0.06934、τ=109.70 ns。
    单极点模型在最小二乘意义下把两个真实极点"平均"成一个,幅度上多补一点来
    补偿时间形状的错配。这是**可预期的物理行为**,不是拟合失败。
  - **cascade 的参考值不是逐级幅度(重要,别搞错)**:级联两个 single_exp 得
    H=H₁H₂,其阶跃响应是 2 极点和,权重是**部分分式留数**
    `r₁ = A₁(1−A₂) + A₁A₂·τ₁/(τ₁−τ₂)`、`r₂ = (1−A₁)A₂ − A₁A₂·τ₂/(τ₁−τ₂)`
    = **(0.0480, 0.0305)**,其和恰为总阶跃亏损 1−(1−A₁)(1−A₂)=0.0785(已解析核实)。
    朴素地拿 (0.05, 0.03) 当真值会误判拟合偏了 4%。极点位置不变(50, 200 ns)。
  - **双线性离散精确保留极点、微扰留数**:cascade 在 K=2 下 τ 的相对误差
    **2.09e-06 / 1.30e-07**,而幅度的相对误差 **2.50e-03 / 6.25e-04** —— 差约 3–4 个
    数量级。因为 `CascadeDistortion.apply` 是**逐级双线性离散 IIR**(不是解析连续时间),
    双线性变换把 s 平面极点精确映到 z 平面,但会微扰留数约 0.25%。
    交叉验证:`max|cascade_step − 解析 2 极点形式| = 1.4e-4`,与留数偏移同量级。
    对照 multi2(真值本身就是解析多指数)在 K=2 下幅度/τ 相对误差**都是 ~1e-8/1e-9**。
- **关键数值**(脚本 stdout 逐行打印):

  | 真值 | 真实阶数 | rms(K=1) | rms(K=2) | rms(K=3) | rms(K=4) | rms(K=5) |
  |---|---|---|---|---|---|---|
  | single | 1 | **0(精确)** | 8.87e-11 | 1.40e-07 | 1.87e-08 | 1.51e-08 |
  | multi2 | 2 | 2.19e-03 | **3.81e-11** | 2.90e-09 | 2.61e-08 | 3.28e-16 |
  | cascade | 2 | 2.36e-03 | **1.35e-15** | 3.53e-08 | 1.54e-04 | 3.02e-10 |

  K=1 折中参数:single A=0.05000/τ=100.00(精确);multi2 A=0.05303/τ=172.47;
  cascade A=0.06934/τ=109.70。
  正确阶数下的相对回收误差:single **0 / 0**(精确);
  multi2 A=7.16e-09, 1.74e-08 / τ=1.04e-08, 2.13e-08;
  cascade A=2.50e-03, 6.25e-04 / τ=2.09e-06, 1.30e-07。
- **实现注记(诚实标注)**:
  1. **rms vs K 在 K>K_true 处非单调,这是真实行为不是 bug**。multi2 在 K=5 反而降到
     3.28e-16(优于 K=2),cascade 在 K=4 反弹到 1.54e-04(比 K=1 之外最差)。原因是
     `curve_fit` 过参数化时落进**不同的局部极小**、参数退化(见 P2 节里 K=3 的
     0.00806+0.01194=0.0200 分裂)。因此**不能**把「argmin over K」当作阶数选择准则 ——
     图里标注的是**已知的真实极点数**,不是 argmin(multi2 的 argmin 落在 K=5)。
     可靠的陈述是:**K 达到真实极点数时 rms 暴跌约 8 个数量级,之后在噪声量级散布**。
  2. **精确拟合(rms=0、相对误差=0)在对数轴上无法显示**,被 clip 到 1e-16 会读成
     "很小但非零"。(c) 用箭头标注 "exact (rms = 0)",(d) 用竖排 "exact" 文字标注,
     避免误读。
  3. **(a) 故意不加放大 inset**:阶跃只跨 0.94–1.0,该面板的自然 y 范围本身就是放大,
     inset 只会挡住它要放大的曲线。

## P4 ⭐ — 改善因子 vs 失真强度

图文件:`P4_improvement_vs_strength/improvement_vs_strength_sqc.png/.pdf`,
数据:`P4_improvement_vs_strength/improvement_vs_strength_sqc.npz`

> **本图推翻了骨架的原始命题。** 骨架写:「失真变强 → uncorrected rmse 上升而
> corrected 保持平坦 → **improvement 增长**」。实测**方向相反**:improvement
> **随强度单调下降**(∝1/A)。下面「物理含义」给出为什么。

- **展示**:`PredistortionValidationWorkflow` 扫注入尾幅度 A(12 点,0.005–0.50),
  两场景各一遍(沿用 P2 的 matched / mismatch 定义,目标波形也与 P2 完全相同的
  flat-top,便于两图对读)。**两场景注入同一总幅度**,只有极点结构不同 —— 故
  uncorrected 误差在每个 A 上一致(实测差 ~0.4%),把模型失配隔离为 corrected
  差异的唯一成因。灰色阴影 = A>0.10,即 `design_inverse` docstring 声明的
  Rol 2020 验证范围之外,属外推。2×2 面板:
  (a) rmse vs A(log-log,标出实测幂律);(b) **⭐ improvement vs A**;
  (c) settling 时间 vs A;(d) AWG 需要摆到的绝对幅度带。
- **如何读**:
  - (a) 黑线(uncorrected,两场景重合)斜率 **1.0000**;橙线(mismatch corrected)
    斜率 **2.06**;蓝线(matched corrected)在 8e-16..2e-12 之间**锯齿跳动** ——
    那是浮点舍入,不是物理。灰点线是 10⁻³ 容限:橙线在 A≈0.05 附近穿过它。
  - (b) **本图的结论面板**:橙线与黑点 1/A 参考线**逐点重合**(×1577 @ A=0.005 →
    ×12.68 @ A=0.50);蓝线在 1e10–1e14 之间乱跳,**无趋势**。
  - (c) 蓝空心圈**全程贴 y=0**(matched 始终在容限内);橙方块在 A≤0.06 与它重合,
    **A=0.08 突然跳到 286.5 ns**,随后爬向黑线(uncorrected,500 ns=窗内从未整定)。
  - (d) 带高 = DAC 为了在片上放出单位脉冲必须摆的范围。A=0.50 时达 **2.82×**
    理想值(−0.86..+1.97)。
- **物理含义**:
  - **为什么 improvement ∝ 1/A**(核心)。uncorrected 误差就是失真本身,严格线性于
    A(实测 A^1.0000,`unc/A` = 0.41864 常数到 5 位有效数字)。而校正后的残差来自
    **模型失配**,是 A 的**二阶量**(实测 A^2.06)。两者相除给出 A^−1.06。
    直觉:标定把传递函数拟合到 A 的一阶精度,失配残留在二阶交叉项;失真越强,
    二阶项相对一阶项的占比越大,于是"能纠掉的比例"下降。
    **实用推论:预失真对弱失真最有效**。器件失真越大,越不能靠预失真救,必须从
    硬件端(滤波、阻抗匹配)压低 A 本身。
  - **matched 场景为什么必须画但不能解读为趋势**。matched 下拟合类==真值类 →
    逆滤波器代数精确抵消 → corrected rmse 是纯舍入误差(见 P2/P3)。
    它在图上的作用是**对照**:证明 pipeline 无实现错误,同时直观展示"同义反复的
    改善因子"长什么样(锯齿、跨 4 个数量级、与 A 无关)。**骨架原计划只扫 matched,
    那样 (b) 会是一条 ~1e12 的无意义锯齿线,整图没有信息量。**
  - **settling 有硬阈值,这是最具工程意义的一条**。存在一个最大失真强度
    (本配置 **A≈0.06–0.08 之间**),超过它预失真**无法再满足 10⁻³ 整定指标**。
    这不是渐变而是**穿越**:残差峰值一旦越过容限,settling 从 0 跳到几百 ns。
    定标定指标时应当以此为界。
  - **动态范围是第二个硬约束**。校正靠"边沿过冲 + 尾部下垂"换取片上平坦,代价是
    DAC 摆幅。A=0.50 时需要 2.82 倍理想摆幅 —— 真实 AWG 会先撞上满量程削波,
    这会**在 rmse 曲线之前**成为实际瓶颈(本仿真未建模削波)。
- **关键数值**(脚本 stdout 逐点打印):

  | A | unc rmse | mismatch cor rmse | mismatch impr | mismatch set_cor | AWG 摆幅 |
  |---|---|---|---|---|---|
  | 0.005 | 2.093e-3 | 1.327e-6 | **×1577** | 0 ns | 1.009 |
  | 0.01 | 4.186e-3 | 5.346e-6 | ×783.1 | 0 ns | 1.018 |
  | 0.02 | 8.373e-3 | 2.139e-5 | ×391.4 | 0 ns | 1.036 |
  | 0.04 | 1.675e-2 | 1.023e-4 | ×163.7 | 0 ns | 1.073 |
  | 0.06 | 2.512e-2 | 2.334e-4 | ×107.6 | **0 ns(末次合格)** | 1.112 |
  | 0.08 | 3.349e-2 | 3.756e-4 | ×89.16 | **286.5 ns(失效)** | 1.152 |
  | 0.10 | 4.186e-2 | 6.084e-4 | ×68.81 | 319.5 ns | 1.195 |
  | 0.20 | 8.373e-2 | 2.609e-3 | ×32.10 | 405.5 ns | 1.443 |
  | 0.50 | 2.093e-1 | 1.651e-2 | ×12.68 | 499.5 ns | **2.824** |

  幂律:`rmse_unc ∝ A^1.0000`、`rmse_cor(mismatch) ∝ A^2.0572`
  → `improvement ∝ A^−1.0572`。matched 的 corrected rmse **无幂律**
  (拟合出的 A^−0.42 是对舍入噪声做 log-log 的产物)。
  A=0.05 处与 P2 交叉核对一致:unc 2.512e-2 / cor 2.334e-4 / ×107.6 ≈ P2 的 ×108。
- **实现注记(诚实标注)**:
  1. **不给 matched 标幂律**。曾在图例里对两场景都标 `∝A^slope`,其中 matched 得到
     `A^−0.42` —— 那是对 8e-16..2e-12 的浮点噪声做 log-log 拟合的**产物**,当作幂律
     展示会误导。现在图例与 stdout 都把它明确写成 "floating-point noise, no trend"。
  2. **A>0.10 是外推,已用灰色阴影标出**。`SingleExponentialDistortion.design_inverse`
     的 docstring 声明 Rol 2020 验证范围是 |A|≤0.1(且 |A|>0.5 会 `warnings.warn`)。
     A≥0.15 的点物理上仍自洽(逆滤波器仍稳定),但**超出文献验证区间**,报告引用时
     应当限定在 A≤0.1,阴影区只用于展示"失效趋势"。
  3. **settling=0 的语义**。[`_settling_time`](../../sqc/workflows/predistortion_validation.py#L195)
     在波形**从未**超出容限时返回 **0.0**,在从未整定时返回窗口末端(~499.5)。
     所以 (c) 里 y=0 读作"全程合格"而非"瞬间整定",y≈500 读作"窗内没整定完"。
     A=0.005 处 uncorrected 是 388.5 ns(不是 500)—— 尾幅足够小,窗内确实整定了。
  4. **(c) matched 用大号空心圈画在下层**:它全程 y=0,而 mismatch 在 A≤0.06 与它
     重合;若同号同实心,蓝点会被橙方块完全盖住,读者会误以为 matched 从 A=0.08 才
     开始。现在蓝圈环绕橙方块,重合关系可见。
  5. **(d) 一轴一量纲**。早期版本把"峰峰值(差值)"和"min..max 带(绝对值)"画在同一
     y 轴,混淆两种量纲。现在只画绝对幅度,峰峰值作为**带高**读出,并在右端标注。
  6. **未建模 DAC 削波**。(d) 只报告"需要多大摆幅",不模拟超出量程后的非线性削波。
     真实系统在 A 较大时会先受削波限制,实际可用改善会**低于**本图的 mismatch 曲线。

> **先说一句更正。** 本节早期草稿把 (b) 面板的残差称为「量子测量精度底 / noise

## P6 ⭐ — 协议驱动的端到端预失真标定: cryoscope vs transient

图文件:`P6_protocol_comparison/protocol_comparison_sqc.png/.pdf`,
数据:`P6_protocol_comparison/protocol_comparison_sqc.npz`

- **展示**:2×2 面板。(a) 两协议重建的阶跃响应 + 解析真值;(b) 独立验证波形
  (CZ 型 flat-top)三种片上波形 + AWG 预失真内嵌图;(c) 时域绝对残差(log y);
  (d) RMSE 条形图。
- **核心结果**:
  - **Cryoscope**:成功重建阶跃响应(rmse 0.0034),预失真降低验证 RMSE 从 1.48e-2
    到 1.09e-3(**×13.5**)。拟合 A=0.055, τ=135.9 ns(真值双指数
    0.04@80ns+0.02@400ns 的合理加权平均)。
  - **Transient (Wiener)**:线性核近似在当前步进幅度(0.05 Φ₀)下不足以重建阶跃响应。
    重建幅度偏离 ~3×,预失真失败(验证 RMSE ~213 Φ₀)。这是线性核物理限制,
    不是代码缺陷。Hammerstein 路径当前存在单位 bug(Wiener 输出是 flux 但被当作
    frequency 输入 ω→Φ 转换),修复后可为瞬态协议提供非线性校正路径。
- **公平性**:
  - 两协议共享同一控制线真值、同一输入阶跃、同一 qubit 模型、同一训练/验证划分。
  - Cryoscope 在 sweet spot(flux=0,自动设置),transient 在 max-sensitivity bias
    (~0.10 Φ₀,自动设置)。各自取最优工作点。
  - 拟合均为 single_exp(对 multi_exp 真值故意欠拟合)。
- **空对照**:理想线(无失真) cryoscope 测量已产生并保存在 NPZ 中。
- **实现注记**:
  1. `_ProtocolDrivenMeasurement._auto_flux_bias()`(新增,替代原 `_warn_flux_bias`)
     自动为每个协议设置正确的 flux bias,使用 `qubit.change_flux()` 确保内部状态
     (EJ, frequency, anharmonicity)同步更新。
  2. Cryoscope 有效窗口 20.5–90 ns 不能完整捕获 400 ns 慢尾;拟合 A 偏低 8.6%
     (相对总亏损 0.059)。对 τ ≤ 100 ns 的单尾失真,该窗口足够。
  3. Transient 的失败是**物理结论而非实现 bug**:图已清楚标示"reconstruction failed
     — linear kernel insufficient at this amplitude"。

## P7 ⭐ — 预失真对 CZ 门性能的影响

图文件:`P7_cz_gate_impact/cz_gate_impact_sqc.png/.pdf`,
数据:`P7_cz_gate_impact/cz_gate_impact_sqc.npz`

- **展示**:2×2 面板。(a) 三组片上磁通轨迹 + AWG 波形内嵌图;(b) 门指标分组柱状图
  (条件相位误差、泄漏、不保真度,三纵轴独立);(c) 片上磁通残差(log y);
  (d) 鲁棒性扫描:门不保真度 vs 失真强度 A(τ=80 ns 固定)。
- **核心结果**:

  | 指标 | Ideal | Uncorrected | Corrected |
  |---|---|---|---|
  | 条件相位 (rad) | 2.68 | 1.11 | 2.60 |
  | 相位误差 (rad) | 0.458 | 2.031 | 0.544 |
  | 泄漏 | 0.169 | 0.010 | 0.165 |
  | 不保真度 | 0.294 | 0.441 | 0.297 |
  | 附加相位误差 | — | +1.573 | **+0.086** |
  | 附加不保真度 | — | +0.146 | **+0.003** |

  - **预失真几乎完全恢复理想门性能**:附加相位误差从 +1.57 rad 降至 +0.09 rad,
    附加不保真度从 +0.146 降至 +0.003。
  - **通量 RMSE 改善 ×28.6**(6.07e-3 → 2.12e-4)。
  - **鲁棒性**:预失真在 A ≤ 0.08 范围内有效;超过此值,single_exp 对 multi_exp
    真值的拟合退化,逆滤波器质量下降。
- **门指标定义**(README 详述):
  - 条件相位:φ_CZ = |arg(⟨11|U|11⟩) − arg(⟨01|U|01⟩) − arg(⟨10|U|10⟩) + arg(⟨00|U|00⟩)|
  - 泄漏:1 − (1/4) Σ_i Σ_{j∈comp} |⟨j|U|i⟩|²
  - 平均门保真度:F_avg = (|Tr(U_ideal† U_eff)|² + d)/(d(d+1)), d=4
  - Virtual Z 校正后计算;所有四个计算基态分别演化(非单输入态)。
- **门参数冻结**:理想、未校正、校正三组使用**完全相同**的门时长、幅度、耦合、flux bias
  和求解器设置。仅片上磁通波形不同。
- **波形驱动的 CZ 仿真**:新增 `sqc/control/gates.py::simulate_cz_from_flux(t, phi_chip,
  qubit1, qubit2, g)` 接收显式时间和片上磁通,内部通过 transmon 色散关系
  Φ → ω(Φ) 转换为失谐,构建完整时变两 qubit Hamiltonian,用 QuTiP `propagator`
  求解完整演化算符。
- **实现注记**:
  1. `simulate_cz_from_flux` 的 Φ→ω 转换使用 `QubitSpec.frequency(flux)` 的精确
     Transmon 色散 ω(Φ) = √(8·EC·EJ|cos(πΦ)|) − EC,单位保持 rad·GHz 与 Hamiltonian
     一致。不除以 2π。
  2. Cryoscope 拟合的 `|amplitude|` 在某些高失真扫描点触发 `> 0.5` 的 Rol 2020 范围
     警告 —— 属预期行为(外推区间)。
  3. 理想基线 cond_phase=2.68 rad(误差 0.46 rad)尚未达到完美 CZ —— 这是简单 sin²
     包络 + 短时长(T=44.4 ns)的限制,与预失真问题正交。图 E2 的比较(理想 vs 未校正
     vs 校正)在**同一不完美基线**上进行,相对改善的结论不依赖于基线的绝对性能。
  4. (b) 面板三纵轴独立标注,避免不同量纲混在同一数值轴。柱体上直接标数值。
